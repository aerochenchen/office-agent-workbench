# 结构层次序数与字体（GB/T 9704-2012）

Agent 在 Step 2 标注角色时必读。脚本按 `role` 施加样式，并对**西式二级标号做确定性转换**（不依赖 Agent 是否填写 `text`）。

## 正文结构层次（核心）

| 层次 | role | 标号格式 | 中文字体 | 字号 | 缩进 |
|------|------|----------|----------|------|------|
| 第一层 | `h1` | 一、二、三、… | **黑体** | 三号 16pt | 首行缩进 2 汉字 |
| 第二层 | `h2` | （一）（二）（三）… | **楷体_GB2312** | 三号 16pt | 同上 |
| 第三层 | `h3` | 1. 2. 3. … | **仿宋_GB2312** | 三号 16pt | 同上 |
| 第四层 | `h4` | （1）（2）（3）… | **仿宋_GB2312** | 三号 16pt | 同上 |
| 正文 | `body` | 无层次序数 | **仿宋_GB2312** | 三号 16pt | 同上 |

规则：

- 层次序数本身是正文的一部分，不是 Word「标题样式」；不要改成 Heading 1/2。
- 回行顶格；段前段后 0；固定行距 29 磅；两端对齐。
- 英文与阿拉伯数字在 run 级用 Times New Roman（脚本自动设 ascii/hAnsi）。

## 西式 / 非标编号 → 国标

| 原文形态 | 判定 | 改为 | role |
|----------|------|------|------|
| `一、` / `二、` … | 第一层 | 保持 | `h1` |
| `（一）` / `(一)` | 第二层 | 全角「（一）」 | `h2` |
| `1.1` / `2.3` / `3.2.1` 等西式多级 | 第二层 | 「（一）」「（二）」… | `h2` |
| 单独 `1.` `2.`（非 `1.1`） | 第三层 | 保持「1. 」 | `h3` |
| `（1）` / `(1)` | 第四层 | 全角「（1）」 | `h4` |

**apply 自动转换（默认）**：

1. 段首匹配 `1.1` / `2.2 标题` 等 → 升为 `h2`，改为「（一）标题」；每个 `h1` 下从（一）重计。
2. 段首半角 `(一)` → 全角并按组重计。
3. Agent 已写 `text` 但仍含西式标号时，再改一次。
4. dump 提供 `hint_role` / `hint_text` / `needs_numbering_fix`。

```
原文: 2.1 贯通业务流程
apply 后: （一）贯通业务流程（楷体，h2）
```

## 版头 / 主体 / 版记角色

| role | 含义 | 字体要点 |
|------|------|----------|
| `masthead` | 发文机关标志 | 方正小标宋简体，红色，居中 |
| `copy_no` | 份号 | 黑体三号，顶格 |
| `secrecy` | 密级与保密期限 | 黑体三号，顶格 |
| `urgency` | 紧急程度 | 黑体三号，顶格 |
| `doc_number` | 发文字号 | 仿宋三号，居中（下行文） |
| `signer` | 签发人行 | 「签发人」仿宋，姓名宜楷体（脚本整段仿宋；精细拆 run 可人工） |
| `title` | 公文标题 | 方正小标宋简体，二号，居中，黑色 |
| `main_recipient` | 主送机关 | 仿宋三号，顶格，末全角冒号 |
| `attachment_note` | 附件说明 | 仿宋，左空 2 字「附件：」 |
| `signature` | 发文机关署名 | 仿宋，右对齐（位置细则见 layout） |
| `date` | 成文日期 | 仿宋，右对齐 |
| `annotation` | 附注 | 仿宋，左空 2 字加圆括号 |
| `annex_label` | 附件首页「附件」标 | 黑体三号 |
| `copy_to` | 抄送 | 四号仿宋 |
| `print_info` | 印发机关和日期 | 四号仿宋 |
| `empty` | 空段 | 无缩进 |
| `skip` | 不改样式 | 脚本跳过该段 |

## `roles.json` 约定

```json
{
  "source": "某公文.docx",
  "red_line_after": 3,
  "notes": ["印章位置需人工复核"],
  "paragraphs": [
    {"index": 0, "role": "masthead"},
    {"index": 3, "role": "doc_number"},
    {"index": 5, "role": "title"},
    {"index": 6, "role": "main_recipient"},
    {"index": 8, "role": "h1"},
    {"index": 9, "role": "h2", "text": "（一）贯通业务流程"},
    {"index": 10, "role": "body"}
  ]
}
```

- `red_line_after`：发文字号段 index，脚本在该段底加红色分隔线；无发文字号则省略该字段。
- 每个非 `skip` 段落都应有标注；未标注段脚本会兜底为 `body`/`empty` 并在 warnings 中列出。
- `text` 仅在需要改标号或纠错时填写（整段替换）。
