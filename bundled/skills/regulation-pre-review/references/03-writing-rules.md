# 03 结论措辞与引用格式

## 一、结论四档 + 待补

| 结论 | 用在哪 | 表中呈现 |
| --- | --- | --- |
| 符合 | 无需修改 | `符合。` + 一句肯定（可省） |
| 基本符合 | 可用，但建议优化；不构成否决 | `基本符合：` + 现象 + 建议 |
| 不符合 | 必须修改才可发布 | `不符合：` + 问题 + 改法 |
| 不适用 | 本制度不存在该情形 | `不适用。` + 一句理由（如"本站无地域差异事项"） |
| 待补 | 材料缺失，判不了 | `待补：` + 缺什么 + 由谁补 |

一句话原则：**结论词在前，冒号后先说问题、再说改法。**

## 二、意见句式

- 改法用祈使句，给可替换的表述，不给"请进一步完善"这类空话
  - ✗ 「报告时限需要完善」
  - ✓ 「建议改为"发现后1小时内上报"，与《××信息报告办法》一致」
- 一处问题只写一条意见，不并列三个诉求
- 涉及引用原文用「」，长条文摘关键短语，不整条照搬
- 定位到条：`第X条`；定位到款：`第X条第Y款`；定位到章：`第X章`
- 无法定位（通篇问题）写「全文」并举例，如「全文"及时/尽快"共3处（第六条、第八条）」

## 三、字数控制（决定表格能否排满两页）

| 位 | 上限 | 超了怎么办 |
| --- | --- | --- |
| 单条意见 | 60 字 | 拆：问题进意见栏，细节进底稿 |
| 其他修改意见 | 3 条 × 45 字 | 更多写入底稿「其他意见（扩展）」 |
| 规章名称 | 40 字 | 用简称不加书名号也可 |

表格 D 列每行约 16 字，60 字≈4 行，22 条全满也不超两页。

## 四、不能写的东西

- 不写具体法条原文除非已核对（可用"依据《××》关于××的规定"）
- 不写"经审查，该制度完全符合"这类全称判断
- 不写对起草部门的人身评价
- 不写涉密事项的具体内容；涉密材料只写"另附"

## 五、其他修改意见和建议（表第三部分）

只放**跨条、跨制度**的问题：
- 与某项制度的联动修订需求
- 需要补充的配套文件（表单、清单、流程图）
- 需要提请上级明确的事项

单条意见里已说过的不再重复。
