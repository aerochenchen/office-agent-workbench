# 02 22 条审查要点判定口径

四项维度：合法合规性（1—9）、合理性（10—14）、可操作性（15—17）、规范性（18—22）。
每条：**查什么 → 常见缺陷 → 判分标尺**。

---

## 一、合法合规性

### 1. 是否符合党中央国务院民航局及空管局法治建设部署、行业发展导向
- 查：制度目的是否对得上当期行业主线（安全、低空经济、智慧空管、法治建设）
- 缺陷：只写"加强管理"不提导向；把内部管理事项写成行业政策
- 判分：能对应上级部署表述 → 符合；目的空泛但与导向不冲突 → 基本符合；与导向相背 → 不符合

### 2. 是否与法律、行政法规、部门规章、民航局规范性文件、上级制度违背
- 查：第一条依据是否列全、名称是否准确、是否落到条款；正文实体规则有无与上位规定相反
- 缺陷：依据只写一部法且条款不落；引用已废止文件；上位要求"应当"本制度写"可以"
- 判分：依据不全但实体不违背 → 基本符合；实体规则与上位规定相反 → 不符合

### 3. 是否与本单位职责匹配、有无越权
- 查：有无设定行政处罚（罚款、没收、吊扣）、行政强制、许可条件、收费；有无对非管理对象设定义务
- 缺陷：自设罚则（最常见、最硬伤）；自设审批；给其他单位（含驻场单位、地方政府部门）派任务
- 判分：越权设罚则/许可/强制 → 不符合，且结论一般取"审查不通过"

### 4. 制定必要性是否充分、能否用自律或简易措施解决
- 查：是否可通过修订现行制度、发通知、纳入预案解决；是否一事一制度
- 判分：确有必要 → 符合；可并入现行制度 → 基本符合（建议合并）；纯重复 → 基本符合并提示

### 5. 是否贴合空管发展趋势、兼顾持续安全与高质量发展
- 判分：与当期形势对应 → 符合；无明显对应但不滞后 → 基本符合

### 6. 制定目的和管理目标是否清晰、是否紧扣合规管理/安全运行/风险防控
- 查：第一条是否一句话说清"解决什么问题"；有无可检验的管理目标
- 判分：目的清晰 → 符合；目的空泛 → 基本符合

### 7. 内容是否滞后、能否指导实际工作
- 查：引用的技术标准、机构名称、系统名称是否现行；流程是否与实际作业不符
- 判分：明显滞后（旧机构名、废止标准） → 基本符合或不符

### 8. 与本单位现行有效制度是否重复、冲突，新旧衔接是否清晰
- 查：同一事项的报告时限、审批层级、责任部门是否与现行制度一致；有无"一事两制"
- 缺陷：报告时限不一致（高频硬伤）；同一事项两套流程；旧制度未废止
- 判分：硬冲突 → 不符合；表述重复但可并存 → 基本符合

### 9. 跨部门跨岗位协同是否完成会商并达成一致
- 查：稿内是否载明会商；是否有会商纪要；涉及驻场单位/地方部门的条款是否经其同意
- 判分：无会商记录但涉及多部门职责 → 不符合（可写"待补会商纪要"）；仅内部科室 → 不适用

## 二、合理性

### 10. 职责设定是否匹配职能、层级部门岗位是否明确、有无缺失或交叉
- 查：每一动作是否都落到具体部门/岗位；有无"有关部门""相关部门"；同一动作两个主体
- 缺陷：报告主体交叉（现场人员直接报 + 部门负责报）；只有"负责"没有"谁来做"
- 判分：主体交叉/缺失 → 不符合；表述笼统但主体唯一 → 基本符合

### 11. 对管理对象和相关方的义务性规定是否适度、有无增加不必要负担
- 查：要求报送的频次、材料、留痕是否过量；对驻场单位是否重复设义务
- 判分：明显加码 → 基本符合（建议精简）或不符

### 12. 适用范围、管理对象是否界定准确、无歧义
- 查：第二条适用范围是否与制度名称、正文主体一致；定义条款是否把外延放大
- 缺陷：定义过宽（"所有飞行器"）、名称与定义术语不一致
- 判分：界定错误致适用混乱 → 不符合；仅表述不严谨 → 基本符合

### 13. 是否公平公正、权利义务与权责是否统一
- 查：有无只设义务不给权利、只设责任不给保障；奖惩是否对称
- 判分：一般 → 符合

### 14. 地域等差异是否体现共同但有差异原则
- 判分：本单位无地域差异事项 → 不适用；有分支/异地机构未区分 → 基本符合

---

## 三、可操作性

### 15. 流程、步骤是否完整连贯、有无断层或遗漏
- 查：是否闭环——发现/触发 → 报告 → 处置 → 恢复 → 复盘 → 归档
- 缺陷：无复盘整改；无信息报送对象；无终止条件
- 判分：缺关键环节 → 基本符合或不符

### 16. 监督考核措施是否具体、具备检查核查条件
- 查：有无考核项、考核主体、数据来源、频次；"纳入考核"是否落地
- 缺陷：只写"纳入年度考核"却无指标与取数方式
- 判分：无法核查 → 不符合

### 17. 执行要求是否明确、有无难以落地的笼统表述、量化标准是否可衡量
- 查：搜"及时""尽快""加强""必要时""适当""原则上"；有无时限、频次、阈值
- 判分：关键动作无时限/无量化 → 不符合；个别修饰语 → 基本符合

---

## 四、规范性

### 18. 框架结构是否合理、是否需简化细化
- 查：是否具备 总则（目的/依据/范围/定义）— 职责 — 具体管理 — 监督考核 — 附则
- 缺陷：缺定义章、缺附则；条款层级混乱（章下无条、条下无款）
- 判分：缺章级要素 → 基本符合

### 19. 条文逻辑是否通顺、有无前后矛盾/条款冲突/指代不明
- 查：同一部门多种叫法；同一主体前后表述不一；"上述""该部门"指向不明
- 判分：出现自相矛盾 → 不符合；仅称谓不统一 → 基本符合

### 20. 征求意见范围与时间是否合理、意见是否妥善处置
- 查：征求了哪些部门/单位、是否覆盖执行主体与一线岗位、有无意见汇总与采纳说明
- 判分：范围明显不足 → 不符合；有记录但不完整 → 基本符合

### 21. 定义、专业术语是否与法规/政策/行业标准/空管局制度一致，或已有准确界定
- 查：术语表；同一概念是否多词混用（无人机/无人驾驶航空器/飞行器）
- 判分：术语与行业标准冲突 → 不符合；混用未定义 → 基本符合

### 22. 是否明确生效时间、有效期；涉及废止是否明确废止信息与过渡安排
- 查：附则；有无"自发布之日起施行"、有效期、旧制度废止条款、过渡期
- 判分：三项（生效、有效期、废止衔接）缺任一关键项 → 不符合

---

## 判定优先级

1. **先找硬伤**：越权设罚则（3）、与上位法违背（2）、与现行制度硬冲突（8）、术语与标准冲突（21）
2. **再找落地缺陷**：无时限（17）、不可核查（16）、职责交叉（10）
3. **最后补程序与体例**：征求意见（20）、框架（18）、生效废止（22）

一条硬伤足可使结论为「审查不通过」。程序与体例问题不改结论，只写意见。
