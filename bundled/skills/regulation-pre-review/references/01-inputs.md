# 01 输入清单与缺项处理

## 一、必需件

| 项 | 说明 | 缺了怎么办 |
| --- | --- | --- |
| 规章全文 | 拟发布最终稿（docx/pdf/md/txt）。工作稿、征求意见稿不作数 | 无法启动，直接问 |
| 规章名称 | 全称，含「（试行）」「（暂行）」等后缀，与正文标题一字不差 | 取正文标题 |
| 审查方式 | 审查会集中审查 / 自查 | 默认自查，出表后请用户改 |
| 审查日期 | 审查报告日期，写 `YYYY-MM-DD` | 取当天 |

## 二、决定判定质量的材料

| 材料 | 直接影响的要点 | 缺失后果 |
| --- | --- | --- |
| 上位依据清单（法律、行政法规、部门规章、民航局规范性文件、民航局空管局制度） | 2、21 | 无法判「是否违背」，只能判「是否载明依据」 |
| 本单位现行有效制度目录 | 8、22 | 判不了重复、冲突、废止衔接 |
| 部门职责文件（三定方案 / 职责分工） | 3、10、13 | 判不了越权与职责交叉 |
| 征求意见与意见处理记录 | 20 | 判不了范围是否合理、意见是否处置 |
| 跨部门 / 驻场单位会商纪要 | 9 | 只能看稿内有无会商表述 |
| 审查组成员名单（姓名/单位部门/日期） | 签字栏 | 签字栏留空 |
| 拟废止旧制度信息 | 22 | 判不了废止与过渡安排 |

## 三、加分材料

- 涉及的业务流程图、表单、台账（判要点 15 有没有断层）
- 量化指标口径与取数来源（判要点 16、17）
- 上一次同类制度的审查意见 / 上级检查发现的问题（可复用为缺陷线索）

## 四、口径提醒

- 「上级」指民航局、民航局空管局；地区管理局制度属上级还是同级，按本单位制度管理办法界定，不确定就在意见里写「按《××制度管理办法》界定」
- 咨询类、宣教类文件一般不设罚则、不设考核，审查时按要点 16 可判「不适用」
- 试行稿同样要写有效期（要点 22），「试行」不等于可以不定有效期
- 表格类附件（表单）不单独审，按主制度条款一并看
