# 套用到 PPT

在用户确认方案后执行。目标是**整套幻灯片视觉一致**，不是只改封面。

## 套用映射

| 方案角色 | PPT 用法 |
|----------|----------|
| 主色 | 封面底或封面色带、章节页、标题下划线/左侧竖条、表头底 |
| 辅色 | 二级标题、图标描边、图表第二系列、流程未选中态 |
| 强调 | 关键数字、结论句左边线、需行动的条目（每页≤2 处） |
| 背景 | 正文页背景 |
| 正文色 | 标题与正文文字 |
| 弱化 | 页脚、来源、注释 |

## 页面类型

1. **封面**：主色主导；标题用浅色字（若底为主色）或深色字（若底为浅色+色带）。单位名称、会议名称层级清楚。
2. **章节页**：主色色块或宽色带 + 章节序号/标题；留白充足。
3. **正文页**：浅底 + 深字；一级标题可用主色；正文勿用主色浅字。
4. **表格**：表头主色或辅色底 + 浅色字；斑马线用背景的微调灰，不用强调色。
5. **图表**：系列1=主色，系列2=辅色，系列3=强调或更浅辅色；网格线弱化。
6. **结尾页**：与封面呼应，信息少于封面。

## 字体与字号（16:9 常用起点）

| 元素 | 建议 |
|------|------|
| 封面标题 | 32～44 pt，加粗 |
| 章节标题 | 28～36 pt，加粗 |
| 正文标题 | 20～24 pt，加粗 |
| 正文 | 16～18 pt |
| 表格/注释 | 12～14 pt |

会议室后排或培训场景可整体 +2 pt。以方案字体名为准；缺失则回退微软雅黑并告知。

## 可读性自检（套用后必做）

- [ ] 正文页是否浅底深字？
- [ ] 投影场景下灰字是否过浅？
- [ ] 强调色是否铺满整页？（应否）
- [ ] 红系方案是否避免了大红底+小字？
- [ ] 图表是否不用荧光对比色？

## 实现提示

- 优先改主题/母版（若工具链支持），再改单页，减少遗漏。
- 已有 pptx：保留内容结构，替换配色与字体；勿擅自改文稿口径。
- 新建 pptx：先写入母版色与字体，再填内容。
- 依赖以环境为准（如 `python-pptx`）；无脚本能力时按页用可用工具改，并在交付时说明改动范围。

## 不要做

- 未确认方案就改文件  
- 混用两套预置方案的颜色  
- 为「好看」加紫色渐变、玻璃拟态、大阴影卡片风  
- 把本技能用于红头公文版心/公文字体强制（走公文技能）
