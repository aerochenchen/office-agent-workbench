# 按单位主色生成视觉方案

用户给出单位主色（或从 Logo 描述/已有材料抽取）时，按下列规则生成完整方案。生成后须展示确认，再套用。

## 输入

最少需要其一：

- 主色 hex（如 `#003A70`）
- 或近似描述（「国航蓝」「海关蓝」）→ 先落到具体 hex 再继续

可选：辅色、是否党建红系、是否必须打印友好。

## 推导规则

设主色为 `P`（H,S,L 或近似处理即可，不必写脚本）。

| 角色 | 如何得到 | 约束 |
|------|----------|------|
| 主色 | 即 `P`；过亮则加深到宜作标题条 | 投影下勿用高亮荧光作主色 |
| 辅色 | 同色相、降饱和、略提亮或略加深 | 与主色可区分即可 |
| 强调色 | **互补邻近**或暖金色/琥珀色；若 `P` 已是红，强调改用缃金 `#D4A84B` 一类，勿再叠大红 | 每页少用 |
| 背景 | 极浅的同色相灰白，或直接 `#F5F7FA` / `#FAF6F1` | 正文页默认浅底 |
| 正文色 | 近黑 `#1A2332` 系，带一点主色相 | 与背景对比足够 |
| 弱化字 | 中灰，勿浅于 `#8A9096`（浅底时） | 页脚可读 |

### 特殊主色

- **红系（党建/机关红）**：正文页强制浅底深字；红只作色带/标题条；强调用金，不用第二红。
- **已很深的藏青/黑蓝**：辅色略提亮，避免辅色与主色糊成一片。
- **要求打印**：额外输出一版灰度替代说明，或建议同时参考 `dayin-paper` 的层级做法。

## 字体（默认）

- 标题：微软雅黑 Bold / 黑体  
- 正文：微软雅黑  
- 单位若规定「方正*/华文*」等，以单位规范为准并写进方案。

```markdown

## 色板
| 角色 | Hex | 用法 |

| 主色 | #...... | ... |

| 正文 | #...... | ... |

## 字体

- 正文：...

## 禁忌

```

落盘路径：`.office-agent/work/office-visual-design/<简称拼音或英文slug>.md`

## 确认话术

列出色板后问一句：「按此套用到 PPT，还是主色再深/再素一点？」确认后再进入套用。
