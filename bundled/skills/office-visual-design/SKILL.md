# 办公视觉设计

面向机关企事业单位工作人员，为 **PPT 汇报材料**选定或生成一套正式、可读、宜投影的中文视觉方案，并套用到幻灯片。不管红头公文版式（走「公文格式排版」）。

## 何时用 / 何时不用

- **用**：做/改 PPT 时要选风格、配色、字体；用户给了单位主色要出整套方案；说「正式一点」「适合汇报」「投影看得清」。
- **不用**：GB/T 9704 红头公文；纯改文案不改视觉；非 PPT 载体（Word/海报）——本版只覆盖 PPT。

## 输入与产出

```
用户口述场合 / 单位主色(hex) / 已有 .pptx
.office-agent/work/office-visual-design/   # 定制方案落盘（可选）
palettes/*.md                             # 预置场合方案（技能内）
output/*.pptx                             # 套用后的幻灯片
```

## 四步纪律（必须按序）

### Step 1 — 澄清场景（Agent，1 步）

用**一轮**问清（缺什么问什么，已知道的跳过）：

1. **场合**：年度汇报 / 专题调研 / 党建活动 / 安全生产 / 数字化 / 生态发展 / 内部培训 / 数据通报 / 其他
2. **展示**：会议室投影 / 线上投屏 / 还要打印或转 PDF
3. **品牌色**：有无单位指定主色（有则走定制；无则走预置）
4. **对象**：已有 pptx 要改皮肤，还是新建内容时同步套风格

### Step 2 — 选定或生成方案（Agent，1～2 步）

**路径 A — 预置场合方案**（无品牌色）

1. 对照下表推荐 2～3 个候选，用一句话说明气质与适用点（勿一次甩出全部 8 套）。
2. 等用户明确选定后再读对应 `palettes/<id>.md`。

| id | 名称 | 典型场合 |
|----|------|----------|
| zhengwu-navy | 深蓝政务 | 年度汇报、工作总结、正式会议 |
| dangjian-crimson | 庄重中国红 | 党建、重要仪式（慎用大面积红底） |
| fazhan-teal | 青绿发展 | 生态、乡村振兴、绿色转型 |
| shuzhi-steel | 银灰数智 | 数字化、信息化、科技专项 |
| anquan-slate | 钢蓝安全 | 安全生产、应急、督察整改 |
| peixun-warmgray | 暖灰培训 | 内部培训、业务讲解 |
| zhongdian-amber | 琥珀重点 | 数据通报、问题清单、需强调要点 |
| dayin-paper | 素雅纸本 | 需打印/转 PDF、黑白友好 |

**路径 B — 按单位主色生成**（有品牌色）

1. `read_skill` 读 `references/custom-from-brand.md`。
2. 按规则生成完整方案（主/辅/强调/背景/正文 + 字体 + 禁忌）。
3. 展示给用户确认；确认后可写入 `.office-agent/work/office-visual-design/<简称>.md` 便于复用。

### Step 3 — 套用到 PPT（Agent，按页数约 2～6 步）

1. `read_skill` 读 `references/apply-to-pptx.md`。
2. 读取已选方案文件，**整套一致**套用：封面、章节页、正文页、表格/图表、结尾页。
3. 套用后自检：正文对比度、投影浅底深字优先、强调色只用于要点不铺满页。

### Step 4 — 交付确认（Agent，1 步）

向用户简报：方案名、主色 hex、字体、输出路径；询问是否微调（更深/更素/少红等）。

## 步数预算

| 阶段 | 约计步数 |
|------|----------|
| 澄清 + 选/生成方案 | 2～3 |
| 套用 PPT | 2～6 |
| 交付确认 | 1 |
| **合计** | **≈5～10** |

页数很多时：先定方案并改母版/首页样例，确认后再批量套其余页（可分会话）。

## 硬规则

- **原创边界**：使用本技能自带 `palettes/` 与生成规则；禁止照搬外部「主题工厂」的主题名、色值组合或英文文艺命名。
- **先确认后套用**：未获用户明确选择/确认前，不得改 pptx。
- **中文优先**：标题/正文使用方案规定的中文字体；缺字时回退「微软雅黑」，并告知用户。
- **正式场合禁忌**：荧光色、大面积高饱和紫/粉渐变、低对比浅灰字、装饰性贴纸风。
- **党建红**：`dangjian-crimson` 或品牌红作主色时，正文页默认浅底深字；红仅用于标题条、要点、装饰线。
- **与公文技能分工**：法定公文版式不走本技能。
