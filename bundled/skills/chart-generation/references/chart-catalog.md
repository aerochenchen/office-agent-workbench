# 图表类型目录

按用途分组的主流图表类型。每种类型给出：适用场景、数据要求、常见误用（何时不要用）、实现提示。

## A. 比较类（Comparison）— 比较不同类别之间的大小

### 柱状图 / 条形图（Bar / Column Chart）
- **适用**：比较少到中等数量（一般 ≤15-20）类别的数值大小，是最通用、最不容易被误读的图表。
- **数据要求**：一个分类维度 + 一个数值维度。
- **误用**：类别过多导致标签重叠；用来展示随时间变化的趋势（应改用折线图）。
- **提示**：默认按数值排序，不要按字母顺序，除非类别本身有固定顺序（如月份、评分等级）；条形图（横向）比柱状图（纵向）更适合类别名称较长或类别数量较多的情况。

### 分组柱状图（Grouped Bar Chart）
- **适用**：同时比较多个系列在多个类别下的数值（如"各产品线在各季度的销售额"）。
- **数据要求**：一个分类维度 + 一个分组维度 + 一个数值维度。
- **误用**：分组或类别数量一多，柱子会挤成一团，难以比较；超过 3-4 个系列时考虑改用小多图（small multiples）。

### 堆叠柱状图（Stacked Bar Chart）
- **适用**：既要看各部分总量，又要看构成的场景。
- **数据要求**：分类维度 + 子分类维度 + 数值维度，子分类之和构成有意义的总量。
- **误用**：如果读者需要精确比较中间某一段的长度（不是底部对齐的那段），堆叠图很难读——这时改用分组柱状图或独立的小图。

### 雷达图 / 蜘蛛图（Radar Chart）
- **适用**：少数几个实体（2-5 个）在多个维度（一般 ≥3 个）上的综合对比，如产品能力评分、选手多维属性。
- **数据要求**：多个数值维度，且各维度量纲/量级需要可比（通常先归一化到同一量表，如 0-10 分）。
- **误用**：维度超过 8 个或实体超过 5 个时会变成一团乱麻；维度之间没有可比性（单位、量级差异很大）时会产生误导。

## B. 趋势类（Trend）— 展示随时间/顺序的变化

### 折线图（Line Chart）
- **适用**：展示一个或多个系列随时间/有序变量的变化趋势，是趋势类的默认首选。
- **数据要求**：一个有序（通常是时间）维度 + 一个或多个数值系列。
- **误用**：用于无序的分类数据（这会暗示类别之间存在连续过渡关系，是常见的误导）；系列超过 5-6 条时线条会互相遮挡，考虑分面或改用热力图。

### 面积图（Area Chart）
- **适用**：强调趋势下方的"量"或多个系列累加后的总量变化（堆叠面积图）。
- **数据要求**：同折线图；堆叠面积图额外要求各系列相加有意义。
- **误用**：多个非堆叠面积图叠加显示时会互相遮挡，通常应保持半透明或改用折线图。

### K线图 / 蜡烛图（Candlestick Chart）
- **适用**：金融时间序列，需要同时展示开盘、收盘、最高、最低价。
- **数据要求**：时间序列 + OHLC（开高低收）四个数值。
- **误用**：非金融场景生搬硬套（如把普通的"最大值/最小值/平均值"数据画成K线，读者未必能读懂这套约定）。

## C. 占比类（Composition）— 展示部分与整体的关系

### 饼图 / 环形图（Pie / Donut Chart）
- **适用**：展示单一时间点、单一维度下部分占整体的比例，且切片数量很少（一般 ≤5-6 片）。
- **数据要求**：分类维度 + 数值维度，数值之和构成一个有意义的整体（100%）。
- **误用**：切片超过 6 个、切片大小接近难以用角度分辨、需要比较多个饼图之间同一类别的变化——这些场景饼图都不合适，改用柱状图。环形图在视觉上略优于饼图（中心可放总数），但适用边界相同。

### 树状图（Treemap）
- **适用**：展示层级结构下的占比关系，尤其类别数量较多（几十个）时比饼图清晰得多。
- **数据要求**：一个或多个层级的分类维度 + 数值维度（决定矩形面积）。
- **误用**：类别间数值差异极小时，矩形大小难以分辨；不适合展示精确数值比较，只适合展示"大致占比"。

### 旭日图（Sunburst Chart）
- **适用**：多层级占比关系，且希望同时看到每一层的展开（树状图的环形变体）。
- **数据要求**：多层分类维度（父子关系）+ 数值维度。
- **误用**：层级超过 3-4 层时外圈标签会挤在一起难以阅读。

### 瀑布图（Waterfall Chart）
- **适用**：展示从起始值到最终值，经过一系列正负变动的累计过程（如"净利润构成"、"用户增长/流失拆解"）。
- **数据要求**：有序的分类维度（各项变动）+ 数值维度（正负均可）。
- **误用**：项目顺序无意义或变动之间没有累加关系时不适用。

## D. 分布类（Distribution）— 展示数据的分散程度

### 直方图（Histogram）
- **适用**：展示单一数值变量的分布形态（集中趋势、偏态、是否多峰）。
- **数据要求**：一个连续数值变量，且观测值数量较多（通常 ≥30，否则分布形态不可靠）。
- **误用**：把它当柱状图用来比较分类数据；分箱（bin）数量选择不当会掩盖或夸大分布形态，一般需要尝试几种分箱宽度。

### 箱线图（Box Plot）
- **适用**：紧凑地比较多个组的分布（中位数、四分位数、异常值），尤其组数较多、无法逐一画直方图时。
- **数据要求**：分类维度 + 一个连续数值变量，每个类别下有多个观测值。
- **误用**：单个类别观测值太少（<5）时箱线图意义不大；读者不熟悉箱线图约定时需要额外说明或改用更直观的形式。

### 小提琴图（Violin Plot）
- **适用**：在箱线图基础上还想看到分布的具体形状（是否多峰）。
- **数据要求**：同箱线图，且样本量足够大以估计出可靠的密度曲线。
- **误用**：样本量小时密度估计不稳定，图形会产生虚假的"形状"。

## E. 关系类（Relationship）— 展示变量之间的关联

### 散点图（Scatter Plot）
- **适用**：观察两个数值变量之间是否存在关系（线性、非线性、无关），是关系类的默认首选。
- **数据要求**：两个数值变量，观测值一般建议 ≥20 个以看出模式。
- **误用**：点过多（成千上万）会重叠成一团（改用密度图/六边形分箱图）；变量之一其实是分类变量时应改用箱线图或分组柱状图。

### 气泡图（Bubble Chart）
- **适用**：在散点图基础上用气泡大小编码第三个数值变量（有时再用颜色编码第四个分类变量）。
- **数据要求**：三个（或四个）变量，其中一个必须是非负数值（映射到面积，不要映射到半径，否则视觉比例失真）。
- **误用**：编码维度超过 4 个时图表会难以解读；气泡过多时相互遮挡。

### 热力图 / 相关矩阵（Heatmap）
- **适用**：展示两个分类维度交叉下的数值大小（如"各小时各星期的活跃度"），或多变量间的相关系数矩阵。
- **数据要求**：两个分类维度 + 一个数值维度，构成一个矩阵。
- **误用**：颜色量表选择不当（如非对称数据用了对称的双色量表）会造成误读；类别数量过多时格子太小难以分辨。

## F. 排名类（Ranking）— 强调顺序/名次

### 排序条形图 / 棒棒糖图（Sorted Bar / Lollipop Chart）
- **适用**：强调名次而非绝对大小，棒棒糖图在类别很多时比条形图更简洁（减少视觉重量）。
- **数据要求**：分类维度 + 数值维度。
- **误用**：与普通条形图一样，类别过多仍需要考虑只展示 Top N + "其他"。

### 哑铃图（Dumbbell Chart）
- **适用**：展示同一组类别在两个时间点/两个条件下的数值变化和排名变化（如"改革前 vs 改革后"）。
- **数据要求**：分类维度 + 两个数值（起点、终点）。
- **误用**：超过两个时间点时哑铃图无法表达，应改用斜率图（slope chart）或折线图。

### 桑基图用于排名变化时可参考下方"流向类"的桑基/河流图；纯排名随时间变化推荐**斜率图 / 蝴蝶图**（多个折线段连接同一实体在不同时间点的排名）。

## G. 流向 / 层级类（Flow & Hierarchy）

### 漏斗图（Funnel Chart）
- **适用**：展示顺序流程中每一步的转化/流失（如注册漏斗、销售漏斗）。
- **数据要求**：有序的阶段维度 + 数值维度（通常单调递减）。
- **误用**：阶段之间没有真实的顺序/包含关系时不适用。

### 桑基图（Sankey Diagram）
- **适用**：展示多节点之间的流量分配（如能源流向、用户路径转移、预算分配）。
- **数据要求**：源节点、目标节点、流量数值的三元组列表。
- **误用**：节点或连接数量过多（>30-40 条边）时会变成"意大利面条"，难以追踪单条路径。

### 树图 / 组织结构图（Tree / Org Chart）
- **适用**：展示严格的父子层级关系（组织架构、分类体系、决策树）。
- **数据要求**：节点及其父节点的映射关系。
- **误用**：层级很深（>5-6 层）或某一层节点极多时需要允许折叠/展开，而不是一次性铺开。

## H. 地理类（Geographic）

### 分级统计地图（Choropleth Map）
- **适用**：展示某个数值指标在不同地理区域（国家、省份、邮编区）之间的差异。
- **数据要求**：地理区域标识 + 数值指标，区域面积不应与数值本身相关（否则大区域天然更显眼，造成误导——必要时改用等值气泡图或人口正规化处理）。
- **误用**：区域面积差异巨大（如按国土面积而非人口/密度衡量）时容易造成"越大越重要"的错觉。

### 气泡地图（Bubble Map）
- **适用**：数值绑定到具体坐标点（城市、门店、事件地点）而非整片区域时，用气泡大小编码数值。
- **误用**：点过于密集时相互重叠，需要聚类或调整透明度。

## I. 单值 / 仪表盘类（Single Value）

### 仪表盘 / 量表图（Gauge Chart）
- **适用**：展示单一指标相对于目标/阈值的当前水平（如完成率、健康分数），强调"一眼看当前状态"。
- **数据要求**：一个当前值 + 一个量程（最小/最大值），通常还有阈值区间。
- **误用**：多个指标同时展示时大量仪表盘会占用过多空间且难以横向比较，此时改用 KPI 卡片网格或子弹图。

### 子弹图（Bullet Chart）
- **适用**：同仪表盘图的场景，但更紧凑，适合在表格/列表中密集排列多个指标。
- **数据要求**：当前值 + 目标值 + 定性区间（差/中/好）。

### KPI 卡片（Big Number / KPI Card）
- **适用**：单个关键指标 + 与上一周期的对比（如"环比 +12%"），是仪表盘首屏最常见的元素。
- **误用**：当指标背后有值得展示的趋势或构成时，仅用一个大数字会丢失重要信息，应搭配小型趋势线（sparkline）。

## J. 文本类

### 词云（Word Cloud）
- **适用**：非常粗略地展示词频/关键词热度，适合作为引子或装饰性总览，不适合精确分析。
- **数据要求**：词语 + 频次/权重。
- **误用**：这是最容易被过度使用的图表——如果读者需要比较具体两个词的频次差异，词云做不到（字号差异难以精确判断），应改用横向条形图列出 Top N 关键词及其频次。默认优先考虑条形图，只有在"氛围展示"胜过"精确比较"的场景才选词云。
