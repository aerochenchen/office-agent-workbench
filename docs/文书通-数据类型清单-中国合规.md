## 1. 结论摘要

- **无账号体系**：不收集注册姓名、手机号、邮箱、密码；设计规格将「账号体系」列为 Non-Goal。
- **本机为主**：会话、审计、配置、Skill 均落在 `~/.office-agent`（或 `OFFICE_AGENT_DATA`）；工作区文档**不复制**进应用数据目录。
- **会离开本机的数据**：用户对话、按任务读取的文档/检索片段 → 发往用户配置的模型 API（`api_base`，经 host 白名单）。
- **开发者不上收**：当前无自建用户后端、无崩溃/分析遥测、无广告标识符。
- **关键风险点**：数据合规重心在「模型服务提供方」与 `api_base` 是否公网/境外，而非本机 SQLite。

---

## 2. 数据流

```
用户工作区文件夹 ──读写──► Runtime 工具循环
对话 / 文档片段 ──────────► Model Gateway（仅 allowed_hosts）
配置 / 会话 / 审计 ───────► 本机 ~/.office-agent（不上报）
```

| 环节 | 行为 |
|---|---|
| 本机处理 | `config.json`、`db/sessions.sqlite`、`db/audit.sqlite`、`skills/`、工作区文件、可选 RAG 索引 |
| 离机传输 | OpenAI 兼容 Chat Completions：messages + 工具相关上下文 |
| 开发者服务器 | 无（当前产品） |

## 3. 完整数据类型清单

| 编号 | 数据类型 | 字段 / 示例 | PIPL 口径 | 存储位置 | 是否离开本机 | 处理目的 | 必要程度 |
|---|---|---|---|---|---|---|---|
| D01 | 模型 API 密钥 | `api_key` | 一般个人信息（凭据） | `config.json` | 否（作请求鉴权） | 连接模型服务 | 功能必要 |
| D02 | 模型服务配置 | `api_base`、`model`、`allowed_hosts`、`permission_mode`、`max_tool_steps` | 一般（偏好/配置） | `config.json` | 否 | 指定模型与权限 | 功能必要 |
| D03 | 对话与会话 | 用户指令、助手回复、工具上下文、会话标题、`session_id` | 一般；内容或含敏感信息 | `sessions.sqlite` | **是** → 模型 API | 多轮对话与任务 | 功能必要 |
| D04 | 工作区路径 | 用户选定文件夹路径 | 一般（路径或含姓名/单位） | 会话元数据 / 内存 | 否（路径不单独外传） | 沙箱与会话关联 | 功能必要 |
| D05 | 文档与文件内容 | docx/文本、附件相对路径、脚本产出物 | 用户内容；机关材料或属敏感 | 用户工作区 | **是**（按任务读取时） | 读写、排版、汇总、写作 | 功能必要 |
| D06 | RAG 素材索引 | chunk 文本、`source`/`path`、embeddings | 用户内容衍生 | 工作区内索引 JSON（可选 Skill） | 检索片段可能进入模型请求 | 本地检索增强 | 可选功能 |
| D07 | 安全事件审计 | `ts`、`event_type`、`outcome`、`tool`、`error_code`、`session_id`、`actor`（OS 用户名）、`instance_id`、脱敏 `attrs`/`detail`、`turn_id` | 使用日志 | `audit.sqlite` | 否 | 操作与决策可追溯 | 安全必要 |
| D08 | 本地权限请求 ID | permission `uuid` | 一般（本地标识） | 进程内存 | 否 | 高危操作确认 | 功能必要 |
| D09 | 本机 API Token | `OFFICE_AGENT_API_TOKEN`（可选） | 一般 | 环境变量 | 否 | Runtime 本地 HTTP 鉴权 | 安全可选 |
| D10 | 脚本输出片段 | 审计 `detail` 中 stderr 前 500 字 | 使用日志 | `audit.sqlite` | 否 | 失败诊断 | 功能必要 |
| D11 | 已装 Skill 元数据 | skill id、名称、权限声明、脚本 | 一般（扩展配置） | `skills/` | 否（本地导入） | 能力扩展 | 功能必要 |
| D12 | 诊断 JSONL | `ts`、`level`、`event`、`boot_id`/`turn_id` 等结构化字段；禁止正文与 API Key | 使用日志 | `~/.office-agent/logs/` | 否 | 故障定位 | 安全必要 |

> 保留策略：D12 诊断 JSONL 按日滚动并默认保留约 **30 天**；D07 审计库（`audit.sqlite`）本期不设自动过期，由管理员导出后自行保管。

### 审计脱敏说明

`audit._redact_args` 对 `content` / `api_key` / `token` / `password` 等字段脱敏：正文只记长度，凭据完全遮罩，避免审计库成为公文明文池。

## 4. 明确不收集

| 跨 App 追踪 | ATT | 无追踪场景 |

## 5. Apple 隐私营养标签（建议填法）

Apple「收集」指数据**离开设备**且可被开发者或第三方访问（超出实时服务所必需）。**仅本机**存储的会话/审计通常**不勾选**为收集。

| 隐私标签类型 | 是否收集 | 是否关联用户 | 用途 | 填写依据 |
|---|---|---|---|---|
| User Content → Other User Content | **是** | 是（与使用行为关联） | App 功能 | 对话、文档、检索片段发往模型 API |
| Identifiers → User ID | 否 | — | — | 仅本地 session UUID，无账号、不外传 |
| Contact Info | 否 | — | — | 无注册登录 |
| Diagnostics | 否 | — | — | 无崩溃/性能上报 |
| Usage Data | 否 | — | — | 本机 audit 不上报 |
| Location / Purchases / Health 等 | 否 | — | — | 不涉及 |

**第三方：** 用户自配的模型服务（OpenAI 兼容端点）为第三方数据处理者，须在隐私政策列明；当前无分析/广告 SDK Privacy Manifest 问题。若日后引入 SDK，须同步更新本表与 Manifest。

## 6. 敏感个人信息（PIPL）

App **不主动采集**生物识别、行踪轨迹等敏感类别。用户公文/材料中**可能嵌入**身份证号、联系方式、未公开事项等。

建议合规动作：

1. 隐私政策声明「用户内容可能含敏感个人信息」；
2. 首次启动取得知情同意；强调内网模型场景下数据留在单位网络；
3. 保持审计脱敏；
4. 不因拒绝非必要信息而拒绝基本功能（当前无多余权限索取）。

## 7. 数据出境与备案口径

| 场景 | 口径 |
|---|---|
| `api_base` = 单位内网 / 本机模型 | 数据处理发生在境内（或本机），一般不构成向境外提供 |
| `api_base` = 公网 / 境外模型 | 构成向第三方提供个人信息，须评估同意基础 + 出境路径（安全评估 / 标准合同 / 认证 / 2026-09 起小型处理者简化措施） |
| 产品默认值 | 代码默认含公网 DeepSeek 地址；**部署与上架材料须按实际交付配置表述**，安全自评估要求安装后改为内网地址 |

**APP 备案简述建议：** 办公生产力类；数据处理以本机为主；模型服务由用户/部署方配置；无运营方自建用户账号数据库。

## 8. 隐私政策须覆盖的章节（对照清单）

- [ ] 处理者名称与联系方式
- [ ] 处理目的、方式（本清单 D01–D11）
- [ ] 敏感信息说明（用户内容可能含有）
- [ ] 保存期限与删除方式（删除会话、卸载清除 `~/.office-agent`）
- [ ] 用户权利（查阅/删除本机会话数据）
- [ ] 数据出境情况（取决于 `api_base`）
- [ ] 第三方接收方（模型服务商）
- [ ] 未成年人保护规则
- [ ] 公开可访问的隐私政策 URL（App Store 要求）

## 9. 变更触发条件

以下任一发生时，须修订本清单并同步隐私政策 / 隐私标签：

- 增加账号登录、云同步、iCloud、推送、支付；
- 引入分析、崩溃、广告 SDK；
- 默认或强制使用境外模型；
- 从桌面扩展为 iOS/Mac App Store 包并新增系统权限。
