## 2. 我们如何理解「收集」与「处理」

- **本机处理：** 信息仅保存在您的电脑本地，不上传至我们运营的服务器。本应用当前**不设开发者自建的用户账号体系与云端用户数据库**。
- **离开本机：** 为完成智能对话与文书任务，本应用会将您输入的指令，以及按任务需要读取的文档内容或检索片段，发送至**您自行配置**的大模型服务接口（`api_base`）。该服务由相应模型服务提供方运营，适用其自身的服务条款与隐私政策。
- **我们（开发者）不上收：** 当前版本不包含将您的对话、文档、设备标识或使用行为发送至开发者自有分析、广告或崩溃统计服务器的功能。

Apple App Store「App 隐私」标签中的「收集」，通常指数据离开设备且可被开发者或第三方访问。据此，本应用需声明的主要离机数据类型为**用户内容**（见第 4 节）；仅保存在本机的会话与审计日志一般不构成向开发者「收集」上报。

## 3. 我们处理哪些信息

### 3.1 为提供核心功能而在本机保存的信息

下列信息保存在您的设备上（默认目录约为用户主目录下的应用数据目录，或您通过环境变量另行指定的目录），**不会由本应用主动上传至开发者服务器**：

| 类型 | 示例 | 目的 |
|---|---|---|
| 模型服务配置 | 接口地址、模型名称、主机白名单、权限模式等 | 连接您指定的模型服务并控制能力范围 |
| 模型 API 密钥 | 您填写的 `api_key` | 向模型服务鉴权（保存在本机配置中） |
| 对话与会话 | 您的指令、助手回复、会话标题、本地会话标识 | 多轮对话、任务连续执行与历史回顾 |
| 工作区路径 | 您选定的文件夹路径 | 限定文件读写范围、关联会话 |
| 工具审计日志 | 工具名称、时间、脱敏后的参数摘要、成败结果等 | 操作可追溯与安全审计（敏感正文与凭据会脱敏） |
| 已安装技能（Skill） | 技能标识、名称、权限声明、本地脚本等 | 扩展排版、写作等能力 |
| 可选检索索引 | 若您使用相关技能，可能在工作区内生成文本块与向量索引 | 基于本地素材的检索增强写作 |

您选定工作区内的**文档与文件**仍存放在您指定的文件夹中；本应用按任务在沙箱范围内读写，**不会为「备份到开发者云端」之目的复制您的公文全文**。

### 3.2 为完成智能功能而可能离开本机的信息

当您发起对话或触发需模型参与的任务时，本应用可能将以下内容发送至您配置的模型服务：

- 当前及多轮对话消息；
- 为完成任务而读取的文档正文、摘录或检索片段；
- 与工具调用相关的必要上下文。

**处理目的：** 生成回复、规划工具调用、完成排版/汇总/写作等您请求的功能。  
**法律基础（PIPL）：** 履行您使用本应用所必需的合同/服务，以及在适用场景下基于您的同意（尤其当您将接口配置为会处理敏感内容或涉及跨境时）。

### 3.3 我们不会主动收集的信息

本应用**不提供账号注册登录**，因此不收集注册用的姓名、手机号、电子邮箱、密码等。

当前版本亦不主动收集：广告标识符、精确地理位置、通讯录、持续相机/麦克风采集流、支付银行卡信息，也不通过第三方分析/广告 SDK 向开发者上报崩溃或用量统计。

（说明：若您通过 Apple 账户购买付费 App，交易由 Apple 处理，适用 Apple 的隐私政策；我们不会因此获得您的银行卡号。）

### 3.4 关于敏感个人信息

本应用**不主动采集**生物识别、行踪轨迹等敏感个人信息类别。但您放入工作区或输入对话的**公文、材料、笔记**中，可能包含身份证号、联系方式、未公开事项等敏感或内部信息。

请您仅在有权处理的材料上使用本应用，并审慎选择模型服务部署位置（优先本机或单位内网）。一旦内容发往模型服务，将受该服务方的处理规则约束。

## 5. 委托处理、共享、转让与公开披露

### 5.1 模型服务提供方（第三方）

为实现智能功能，您需要自行配置兼容的模型服务接口。向该接口发送的对话与文档相关内容，由**相应模型服务提供方**作为独立或共同的处理角色进行处理。请在使用前阅读并同意该提供方的条款与隐私政策，并确认其部署位置（本机、境内内网、公网或境外）符合您所在单位与适用法律的要求。

我们不会在您不知情的情况下，将您的内容发送至我们另行指定的、与您配置无关的模型服务。

### 5.2 开发者

除您主动联系我们并提供的信息外，当前版本**不向开发者服务器共享**您的对话、文档或设备上的应用数据。

### 5.3 转让与公开披露

我们不会出售您的个人信息。如因合并、分立、重组等需转移个人信息处理相关资产，我们将要求承继方继续受本政策约束，或重新征得您的同意（法律另有规定的除外）。

非经法律要求或获得您的同意，我们不会公开披露您的个人信息。

### 5.4 SDK 与系统组件

当前版本不嵌入面向开发者收集数据的第三方分析、广告类 SDK。本应用运行于 macOS，会使用苹果系统提供的能力（如文件选择对话框、网络访问等），适用 Apple 的系统与隐私规则。

## 6. 存储地点、期限与安全措施

### 6.1 存储地点

- **本机数据：** 存储于您的 Mac 本地磁盘。  
- **模型服务侧：** 若发生离机传输，存储与保留规则由您配置的模型服务提供方决定，可能位于境内或境外机房。

### 6.2 保存期限

- 会话、配置、审计日志：在您保留本应用数据期间持续保存，直至您删除相应会话、清除应用数据或卸载并手动删除残留目录。  
- 工作区文档：由您自行管理，保存期限由您决定。  
- 发往模型服务的内容：以该服务方的保留政策为准。

### 6.3 安全措施

我们采取与业务相匹配的合理措施，包括但不限于：工作区路径沙箱、模型主机白名单、高危操作权限确认、审计日志对正文与凭据脱敏、可选的本机接口访问令牌等。请注意：任何安全措施都无法保证绝对安全，请妥善保管您的设备与 API 密钥，并避免在不可信网络环境下将敏感材料发往公网模型。

## 7. 跨境提供个人信息

本应用本身不运营用于汇聚用户数据的境外服务器。

是否构成向境外提供个人信息，**取决于您配置的模型服务接口地址**：

- 若接口指向**本机或境内单位内网**模型，通常不因本应用而额外产生向境外提供；  
- 若接口指向**境外或境外主体运营的公网模型服务**，则您向该服务发送的内容可能构成跨境提供。此时，请您确认已满足适用的合法基础（如单独同意等），并遵守您所在单位及监管要求；个人开发者场景下还可能适用届时有效的小型个人信息处理者相关简化规则（以监管规定为准）。

我们建议机关与企事业单位用户优先配置**单位审批的内网或本机模型**。
