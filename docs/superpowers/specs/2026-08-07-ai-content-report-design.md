# 文书通 · AI 不当内容举报（Store 11.16）

**日期：** 2026-08-07  
**触发：** Microsoft Store 认证驳回 — Technical requirement 11.16 Live Generative AI Content  
**状态：** 已批准

## 问题

政策要求：含实时生成式 AI 的产品须在应用内提供向开发者举报不当 AI 输出的途径，并据此采取适当措施。当前应用无任何举报入口。

## 方案

应用内对话框 + 系统邮件（mailto），收件人 `wenshutongapp@163.com`。

### 入口

1. 每条 `role === "assistant" && phase === "done"` 的气泡旁「举报」按钮。
2. 设置 → 关于：「举报不当 AI 内容」。

### 对话框

- 可选说明（多行文本）
- 「打开邮件举报」/「取消」
- 成功：提示已打开邮件客户端，请发送
- 失败：提示复制邮箱 `wenshutongapp@163.com`

### 邮件内容

- 主题：`[文书通] 不当 AI 内容举报`
- 正文：用户说明 + 应用版本 +（若有）该条助手回复摘要（截断，控制 mailto 长度）
- 不向开发者服务器自动上传内容

### 非目标

- 自建举报后端 / 网页表单
- 自动采集全文到云端
- 大改隐私政策正文（Partner Center Notes 注明举报路径即可）

## 验收

- [ ] 助手完成回复旁可见「举报」
- [ ] 关于页可见同功能入口
- [ ] 确认后可打开系统邮件且收件人为约定邮箱
- [ ] Notes for certification 写明举报方式，便于复审
