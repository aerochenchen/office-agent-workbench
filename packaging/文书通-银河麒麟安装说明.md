# 文书通 · 银河麒麟 V10 SP1 离线安装说明

适用环境：**银河麒麟桌面 V10 SP1 · 飞腾 / aarch64（arm64）**  
安装方式：**U 盘拷贝 → 断网安装**（全程无需联网）

---

## 一、安装包内容

解压或打开 U 盘中的文件夹（名称类似 `wenshutong-pks-1.5.0-aarch64`），应包含：

| 文件 / 目录 | 说明 |
|-------------|------|
| `wenshutong_<版本>_arm64.deb` | 文书通主程序安装包 |
| `install-offline.sh` | 一键离线安装脚本 |
| `deps/` | 系统依赖离线包（可为空；缺库时由技术人员补充） |
| `deps.manifest` | 依赖说明 |
| `fixtures/` | 验收用样例 Word 文档（可选） |
| `银河麒麟安装说明.md` | 本文档 |
| `验收清单.md` | 安装后功能验收步骤（可选） |

> 若目录中同时存在 `文书通_*.deb` 与 `wenshutong_*.deb`，请优先使用 **`wenshutong_*.deb`**（新版已修正 dpkg 包名与菜单图标）。
>
> 本版依赖 **WebKitGTK 4.0**（麒麟 V10 SP1 自带）。请勿使用仍依赖 `libwebkit2gtk-4.1-0` 的旧包。

---

## 二、安装前准备

1. **确认系统架构**  
   打开终端，执行：
   ```bash
   uname -m
   ```
   应显示 **`aarch64`** 或 **`arm64`**。若为 `x86_64`，本包不适用。

2. **确认已安装 WPS**（后续公文排版、校对需用）  
   ```bash
   which wps
   ```
   常见路径：`/usr/bin/wps`。未安装请先联系管理员安装 WPS ARM64 版。

3. **准备管理员权限**  
   安装过程需要输入本机 **sudo 密码**。

4. **断网（推荐）**  
   验收环境应 **拔掉网线 / 关闭 Wi‑Fi**，确保全程离线。

5. **拷贝安装目录**  
   将 U 盘内整个 `wenshutong-pks-*-aarch64` 文件夹复制到本机，例如：
   ```text
   ~/文档/wenshutong-pks-1.5.0-aarch64/
   ```

---

## 三、安装步骤

### 方法一：推荐（一键脚本）

1. 在文件管理器中进入上述文件夹，**右键 → 在终端中打开**（或在终端中 `cd` 进入该目录）。

2. 执行：
   ```bash
   bash install-offline.sh
   ```

3. 按提示输入管理员密码，等待出现 **`==> Done.`** 即安装完成。

### 方法二：手动安装

若脚本无法运行，可手动执行：

```bash
cd ~/文档/wenshutong-pks-1.5.0-aarch64   # 改为你的实际路径

# 若有 deps 目录下的 .deb，先装依赖
sudo dpkg -i deps/*.deb 2>/dev/null || sudo dpkg --configure -a

# 安装主程序（文件名以实际为准）
sudo dpkg -i wenshutong_1.5.0_arm64.deb
sudo dpkg --configure -a
```

## 四、启动与首次配置

1. 打开 **开始菜单 / 应用列表**，找到 **「文书通」** 并启动。  
   - 菜单图标应为文书通专用图标，而非通用「桌面」图标。

2. 首次使用请在 **设置** 中配置 **内网大模型**：
   - API 地址  
   - 密钥（如有）  
   - 模型名称  

   具体参数请向本单位信息化 / 运维同事索取。

3. **选择工作区**：在软件内指定一个本地文件夹，用于读写公文、材料。

4. **验收测试**（可选）：打开同目录下 `fixtures/` 中的样例 `.docx`，测试「公文排版」「通篇校对」等技能，并确认能用 WPS 打开生成结果。

更详细的勾选式验收表见 **`验收清单.md`**。

## 五、常见问题

### 1. 提示 `dpkg: invalid package name` 或包名报错

**原因**：使用了旧版 `文书通_*.deb`（包名为中文）。  
**处理**：改用目录中的 **`wenshutong_*.deb`** 重新安装；或联系开发获取新版安装包。

### 2. 安装后菜单里没有「文书通」

```bash
sudo dpkg --configure -a
update-desktop-database ~/.local/share/applications 2>/dev/null || true
```

注销或重启后再看应用列表。仍无图标时，在终端执行 `wenshutong` 或从 `/usr/bin/` 查找可执行文件。

### 3. 能看到图标，但启动后没有窗口 / 报 `undefined symbol: webkit_uri_scheme_response_set_http_headers`

**原因**：主程序按 WebKit **2.38** 构建，系统若仍是 **2.28** 会缺符号、进程直接退出。  
**处理**：用新版 U 盘包里的 `deps/`（含 `libwebkit2gtk-4.0-37_2.38.6-…`）重新执行：

```bash
cd ~/桌面/wenshutong-pks-1.5.0-aarch64   # 改为实际路径
bash install-offline.sh
```

或手动升级 WebKit：

```bash
sudo dpkg -i deps/libjavascriptcoregtk-4.0-18_2.38.6*.deb \
             deps/libwebkit2gtk-4.0-37_2.38.6*.deb \
             deps/libsoup2.4-1_*.deb
```

然后再试：

```bash
GDK_BACKEND=x11 WEBKIT_DISABLE_COMPOSITING_MODE=1 /usr/bin/wenshutong
```

若出窗口但仍异常，可再加 `LIBGL_ALWAYS_SOFTWARE=1`。也可临时改菜单：

```bash
sudo sed -i 's|^Exec=.*|Exec=env GDK_BACKEND=x11 WEBKIT_DISABLE_COMPOSITING_MODE=1 wenshutong|' \
  /usr/share/applications/文书通.desktop
```

仍无窗口时，把下面输出一并反馈：

```bash
echo "SESSION=$XDG_SESSION_TYPE DISPLAY=$DISPLAY"
dpkg -l 'libwebkit2gtk*' | grep ^ii
/usr/bin/wenshutong; echo exit:$?
tail -n 80 /tmp/office-agent-desktop.log 2>/dev/null
```

### 4. 启动后提示 Runtime / 服务离线

- 确认安装未中断、未手动删除 `/usr/lib/文书通/` 或类似安装目录下的 runtime 文件。  
- 重新运行 `bash install-offline.sh` 或 `sudo dpkg -i wenshutong_*.deb`。  
- 将终端完整输出截图发给技术支持。

### 5. 提示缺少 `libwebkit2gtk-4.1-0`

本版安装包已改为依赖 **WebKitGTK 4.0**（麒麟 V10 SP1 自带）。若仍看到 4.1，说明用的是旧 U 盘包，请换用新版 `wenshutong-pks-*-aarch64`。

### 6. 安装时提示「即将把 … 降级」

**说明**：旧版脚本会强行安装 `deps/` 里的 Ubuntu 包，可能覆盖系统自带的麒麟版 WebKit。  
**处理**：新版 `install-offline.sh` 在系统已有对应包时会跳过，不再降级。若本次已被降级且担心系统其它软件异常，可在有内网源时由运维恢复麒麟原包；对本程序验收，一般可先直接启动「文书通」验证。

### 7. 缺少共享库（`error while loading shared libraries`）

**处理**：在断网前由技术人员在相同系统上执行 `ldd` 检查，将缺失库的 `.deb` 放入 **`deps/`** 后重新运行 `install-offline.sh`。  
普通用户请将报错原文发给开发同事。

### 8. WPS 无法打开排版结果

确认已安装 **ARM64 版 WPS**，且 `which wps` 有输出。路径非 `/usr/bin/wps` 时，在文书通设置中配置 WPS 路径（若软件提供该选项）。

## 六、卸载

```bash
sudo dpkg -r wenshutong
# 或
sudo apt remove wenshutong
```

用户配置一般在 `~/.config/` 下，卸载主程序不会自动删除，可按单位规范自行备份或清理。
