# 文书通 · PKS 安装验收清单（给非开发人员）

用这份清单，在 **银河麒麟 V10 SP1（飞腾 aarch64）** 上像试用普通软件一样验收。  
**你不需要写代码**，只要：拿到 U 盘里的安装目录 → 断网安装 → 按步骤点 → 勾选「通过 / 未通过」。

技术向步骤见同目录 [VERIFY-kylin-pks.md](./VERIFY-kylin-pks.md)（给会打包 / 测试的人用）。

---

## 开始前准备

### 你需要有人提供

- [ ] U 盘里的整个文件夹，名字类似：`wenshutong-pks-1.5.0-aarch64`（版本号可能不同）
- [ ] 一台 **银河麒麟桌面 V10 SP1 · aarch64** 电脑，已安装 **WPS**（路径常见为 `/usr/bin/wps`）
- [ ] 验收时 **全程断网**（拔网线或关闭无线网络）
- [ ] **内网模型接口**的地址、密钥、模型名（问负责配置的同事；没有这些，对话可能只能测「报错提示是否正常」）
- [ ] 文件夹里的 **`fixtures/`** 样例材料（或同事已帮你拷到桌面 `文书通测试`）：
  - [ ] `sample-format.docx`（测公文排版）
  - [ ] `sample-proofread.docx`（测通篇校对）

### 本版不要求你测的（知道即可）

- 不要求测「写作 RAG 大包」
- 不要求在 Windows / Mac 上做 PKS 正式验收
- 不要求 OFD、电子签章
- 不要求证明「脚本绝对隔离」——有问题记下来交给开发即可

---

## 怎么记结果

每一步勾选：

- ✅ **通过** — 和「期望看到」一致  
- ❌ **未通过** — 写明：点了什么、屏幕上出现什么、能否复现  
- ➖ **跳过** — 缺条件（例如没给 API 密钥）时用，并写原因  

建议另开记事本，记下：**日期、麒麟版本、U 盘文件夹名、测试人**。

## 一、断网安装与启动

| # | 你做什么 | 期望看到 | 结果 |
|---|----------|----------|------|
| 1.1 | 确认电脑 **已断网** | 浏览器打不开外网（可选自测） | ☐ |
| 1.2 | 将 U 盘里整个 `wenshutong-pks-…-aarch64` 拷到本机（如「文档」下） | 拷贝完整，含 `.deb` 和 `install-offline.sh` | ☐ |
| 1.3 | 在该文件夹打开终端，执行：`bash install-offline.sh` | 安装顺利结束；若提示输入密码，用本机管理员账号 | ☐ |
| 1.4 | 打开开始菜单 / 应用列表 | 能看到 **「文书通」** | ☐ |
| 1.5 | 点击启动文书通 | 窗口打开；界面大致是：中间对话、右侧「技能」 | ☐ |
| 1.6 | 看界面是否提示 Runtime / 服务离线 | **不应**一直卡在「离线」；正常应能继续操作 | ☐ |

未通过时：把终端安装输出和屏幕截图发给开发。

## 验收怎么算「过关」

**建议最低标准（B 档）：**

- 第一部分安装启动：1.1～1.6 全部 ✅  
- 第二部分 2.1、2.4 必过；2.2 或 2.3 至少一条 ✅  
- 第五部分排版：5.1～5.4 主路径能走完  
- 第六部分校对：6.1～6.3 主路径能走完  

有一条 ❌ 不等于整个项目失败——把现象记清楚交给开发，修后再测该条即可。

## 和「开发在 Mac 上 Docker 出包」的区别

| | 开发 Mac 出包 | 你这份清单 |
|--|---------------|------------|
| 目的 | 打出可安装的 deb 目录 | 确认 **断网麒麟 + WPS** 上能用 |
| 形态 | 源码 + Docker 脚本 | **U 盘里的安装目录** |
| 谁来做 | 开发 | 你或业务同事 |

若还没有 U 盘目录：先让开发按 [README-kylin-pks.md](./README-kylin-pks.md) 出包，再从本清单「一、断网安装与启动」开始。
